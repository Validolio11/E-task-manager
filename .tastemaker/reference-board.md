# Reference board

Created: 2026-08-25
Mode: Operate
Design read: focus-first task manager for individual desktop and mobile users, with a quiet editorial utility lane.
Dials: variance 4, motion 3, density 5, art direction 6.

## Quality bar
- User-approved local Focus Dock reference: one dominant task, explicit timer start, compact persistent dock.
- iOS interaction language (inferred, not viewed): direct manipulation, soft but controlled settling, safe-area discipline.
- Linear and Things productivity language (inferred, not viewed): restrained chrome and fast scanning.

## Borrow
- Palette/material: approved E-task reference → pale neutral canvas, white floating surfaces, restrained violet accent.
- Type/hierarchy: editorial productivity tools → clear title/timer hierarchy with readable metadata.
- Layout/composition: approved Focus Dock → one central focus object plus a bottom task rail.
- Motion/interaction: iOS-like direct manipulation → immediate press feedback and smooth dock inertia.
- Asset language: existing application → Lucide outline icons and user-selected native emoji.

## Avoid
- Generic indigo gradients, excessive cards, repeated status pills, tiny uppercase labels, mixed shadows, and decorative animation.

## Direction contract
- Thesis: the interface should remove decisions around the next task, not display every metric at once.
- First viewport: current task, planned/elapsed time, one explicit primary action, and the task dock.
- System: tokenized type, spacing, radii, shadows, motion, and state colors on the current React/CSS stack.
- Risk: simplifying so aggressively that secondary workflows become undiscoverable or touch targets become too small.
